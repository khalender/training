Le TD02 a introduit les notions d’accesseur (getter) et de mutateur (setter) pour
accéder aux valeurs ou assigner de nouvelles valeurs aux attributs.

Une tentative de modification d’un attribut privé depuis une autre classe que Dog est

La modification de l’attribut weight ne doit pouvoir se faire que via les méthodes pu-



public final void setWeight(int weight){
if (weight <= 0){
throw new IllegalArgumentException("Le poids doit être un entier positif !");

}

Adaptez aussi le constructeur de façon à refuser les valeurs invalides du paramètre :


2
La visibilité
Nous venons de voir comment modifier la visibilité d’un attribut de façon à le rendre
privé : l’attribut ne peut-être accédé directement que via le code de la classe. Le langage
Java offre plusieurs options de visibilité :
La visibilité en Java
En Java, un attribut ou une méthode d’une classe peuvent-être :
1. Privé : l’attribut n’est accessible qu’au sein même de la classe, utiliser le
mot clé private,
2. Publique : l’attribut est accessible partout (à partir de n’importe quelle
autre classe), utiliser le mot clé public,
3. Package : l’attribut est accessible à partir d’une classe située située dans le
même package, n’utiliser aucun mot clé,
4. Protected : ce type de visibilité est lié à l’héritage (nous en parlerons plus
loin dans le cours de Dev2).
Le code suivant déclare par exemple un attribut name privé, un attribut weight public et
un attribut hungry package (remarquez l’absence de mot clé devant le type de donnée,
boolean, de cet attribut) :


public String name;
private int weight;
boolean hungry;


Bien que cela soit permis par le langage, c’est (en général) une mauvaise idée de
déclarer les attributs publique en Java : cela viole le principe d’encapsulation. On
s’en tient généralement à ce principe :
1. Les attributs sont déclarés private,
2. Des méthodes public permettent d’y accéder.
Déclarer des attributs publique ou package ne se justifie que dans de rares cas, que vous
apprendrez à reconnaître dans la suite de votre apprentissage du langage.

Passage d’argument à une méthode
Nous venons de voir comment modifier un objet dans la méthode main de notre pro-
gramme tout en respectant l’encapsulation. Mais qu’en est-il si nous passons cet objet
en paramètre à une méthode ? De façon générale, une méthode peut-elle modifier les
valeurs des variables qui lui sont passées en paramètre ?

Comme vous pouvez le constater, il est possible de modifier un objet dans une méthode
alors que c’est impossible pour une variable appartenant à un type de donnée primitif.
Types primitifs et types référence en Java
Certains types de données ne sont pas implémentés comme des objets en Java, ce
sont les types primitifs : byte, short, int, long, double, float, boolean et char a.
Tous les autres types de données sont considérés comme des objets et appelés des
types référence.
a. Remarquez que le nom d’un type primitif commence toujours par une minuscule (contrai-
rement aux types références), ceci permet de facilement les reconnaître !
On peut voir une variable d’un type primitif comme un emplacement mémoire contenant
directement la valeur qui lui est assignée. Par exemple :


int i = 7;


peut se représenter au moyen du schéma :
Par contre, un variable d’un type référence contient une référence vers l’objet, qui est
stocké à un certain endroit dans la mémoire. On peut représenter ceci au moyen d’une
flèche, comme illustré sur l’exemple ci-dessous :


Dog médor = new Dog("Médor",4);


médor

Attention : tout type de donnée autre que ceux cités dans l’encadré ci-dessus sont des
types références en Java (que ce type soit lié à une classe écrite par le/la développeur/euse
ou non), y compris les String (chaînes de caractères) et les tableaux :


String s = "Hello";


Lors du passage de paramètre à une méthode, la valeur de la variable est copiée dans le
paramètre de la méthode (qui est une variable locale à la méthode, et détruite à la fin
de son exécution). Dans le cas d’une variable de type référence, la méthode a donc accès
à une référence vers l’objet ce qui explique que l’objet soit modifiable dans la méthode.

La nourriture



public static void feed (Dog myDog, int minWeight)

qui nourrit le chien si son poids est inférieur à minWeight. Pour nourrir un chien, veuillez
